# 蘋果糖 ringo-ame

為 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 製作的響應式雙端介面擴充，保留原生功能與操作流程，重新整理手機與電腦上的視覺、排版及使用體驗。

## 功能特色

- 手機與電腦響應式介面
- 自動、手機、電腦三種顯示模式
- 手機版集中式功能抽屜與 iPhone 安全區域支援
- 桌面版保留 SillyTavern 原有操作習慣
- 聊天搜尋、樓層快速跳轉與回到最新訊息
- 使用 SillyTavern 原生面板與資料，不另外建立重複功能

## 安裝

1. 開啟 SillyTavern 的「擴充功能」。
2. 選擇「安裝擴充功能」。
3. 貼上本專案的 GitHub repository 網址並完成安裝。
4. 重新載入 SillyTavern。

> GitHub repository 公開後會補上可直接複製的安裝網址。

## 使用方式

安裝後，從 SillyTavern 的魔法棒選單開啟「蘋果糖 ringo-ame」，即可選擇自動、手機或電腦模式。顯示偏好會保存在目前瀏覽器。

## 相容性

本擴充只調整 SillyTavern 的介面呈現，不修改 SillyTavern 核心程式。由於 SillyTavern 與第三方主題可能持續更新，建議使用最新穩定版本；最低支援版本仍待確認。

## 開發狀態

目前版本為 `0.1.0`。主要功能已實作並持續於本機 SillyTavern 測試；正式公開發布前仍需完成 GitHub repository 設定。
